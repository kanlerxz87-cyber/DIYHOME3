Where events go

Now: no hosted endpoint is configured (DIY_ANALYTICS_ENDPOINT=""), so events are counted only in your own browser (localStorage) and shown below on this device. Nothing leaves the browser.

To go live: deploy the self-hosted endpoint stub in the repository (analytics/worker.js — a Cloudflare-Worker-style receiver that appends one JSON line per event, storing no IP), then set window.DIY_ANALYTICS_ENDPOINT in docs/assets/app.js to its URL. Instructions: analytics/README.md.
