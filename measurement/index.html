Measurement

The self-hosted collector has five event types. The Pages edition does not send events or report conversions.

EventDefinitionOfficial reference
page_viewPage initialized; not a unique visitor or session.GitHub · Pages limits
guide_viewA guide initialized; also emits a page view.Google · Get started with Search Console
outbound_clickA validated, marked product link was activated. No redirects or interception; not an Amazon-reported click.Amazon · Associates Operating Agreement · Google · Qualify outbound links
feed_clickRSS button activated. Not a subscription or a feed open.Google · Build and submit a sitemap
reported_orderAuthorized aggregate order count from Associates reporting only; never browser-derived.Amazon · Associates help and ASIN glossary

These five names are frozen: the brief did not enumerate them, two sessions proposed different sets, and a rename after collection starts would break comparability with everything already recorded. Add new events as additions, never as renames. See F-21.
