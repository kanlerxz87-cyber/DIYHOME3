The candidate Special Link column is a FORMAT ILLUSTRATION built from the observed ASIN and the supplied tracking ID. It has not been generated by Associates Central, not clicked, and not confirmed in any tracking report. Do not publish it as-is. S01

Why the candidate format is the right shape

“The links must properly use the special “tagged” link formats we provide and comply with this Agreement (“Special Links”).”— Associates Program Operating Agreement, Section 1 S01

The Commission Income Statement then states the consequence of getting the format wrong: it disqualifies "any Product purchase that is not correctly tracked or reported because the links from your site to the relevant Amazon Site are not properly formatted". A malformed link does not merely underperform — the purchase it produces can be excluded entirely. S02

The six-step validation gate

5Confirm the click appears in the tracking reportNoThe click present in Reports with the correct tracking ID and date
6Only then repeat for the remaining ASINs and flip the site to monetisedYesattributionActive set to true in the register, with the tagged href, and a passing build

The brief’s instruction is to test one link per product in the enrolled Associates workflow and confirm destination and tracking report before scaling. Steps 1, 2, 3 and 5 need an authenticated session that this build does not have and should not have.

How to flip the switch

Once steps 1–5 pass for a product, edit its entry in site/data/products.mjs:

observed: {
  …
  outboundHref: 'https://www.amazon.com/dp/B08FKW9JRM?tag=shopnow047c-20',
  attributionActive: true,
  attributionVerifiedOn: '2026-12-01',
  attributionEvidence: 'Associates Central report export 2026-12-01, click recorded',
}

Then run node tools/build.mjs && node tools/verify.mjs. The verifier will fail the build if attributionActive is true while the href carries no tag parameter, or if the verified-on date is missing. It will also fail if the tracking ID in the href does not match the one in the register. The gate is enforced by code, not by memory.

What must never appear in a link on this site

  • A link generated or displayed on a search engine — Commission Income Statement §2(d) disqualifies the resulting purchase.
  • Any paid search placement bidding on "amazon", "kindle", an Amazon Mark, or a misspelling of one — §2(c) calls this a Prohibited Paid Search Placement.
  • A redirect that carries the reader to Amazon without an affirmative click on this site — §2(e).
  • A link with no tag parameter presented as an affiliate link.
  • A link whose destination has not been re-checked within the last 24 hours if the price or availability beside it is being shown.
