Prohibited practices — never to be automated

  • Bidding on "amazon", "kindle", any Amazon Mark, or a misspelling of one in paid search — a Prohibited Paid Search Placement under §2(c).
  • Placing an affiliate link on or generated by a search engine — §2(d).
  • Redirecting a reader to Amazon without an affirmative click on this site — §2(e).
  • Offering any consideration, reward or incentive for using the links, or asking readers to support a cause by using them.
  • Implying that Amazon sponsors, endorses or supports this site, or that there is any affiliation beyond the Associates relationship — §5.
  • Making a public communication about the Agreement or about participation in the programme beyond the required disclosure, without advance written permission — §5. Note that this compliance page quotes the Agreement for operational purposes; whether that needs permission is itself a question for the owner.
  • Storing or caching Program Advertising Content images, or holding a link to one for more than 24 hours — IP License §2(h).
  • Displaying pricing or availability without a date/time stamp and the required disclaimer — IP License §2(i).
  • Reverse-engineering, decompiling or deriving model parameters from PA-API or Creators API — IP License §2(g).
  • Concealing that access is automated, mimicking human keystroke or navigation patterns, or circumventing a CAPTCHA — IP License §4.
One self-flag worth reading twice

The last item on that list is the one this build has the least certainty about. The research behind this register was performed by an automated agent fetching Amazon pages, and this session cannot confirm that those requests carried the "Agent/[agent name]" user-agent string the Agent Terms require, nor that the agent was operating under an enrolled Associates account. The data is recorded as a good-faith observation with that caveat attached rather than presented as clean.
