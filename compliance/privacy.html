What the first-party counter records

assets/js/analytics.js counts five events in your own browser. The counts are five integers stored under one localStorage key on this origin. They are aggregate counts for this browser only, they are not sent anywhere unless a collector endpoint is configured, and they are not this site’s totals.

If a collector endpoint is configured

The reference collector at analytics/server/index.mjs accepts an event name and an optional page path, increments an aggregate counter in a JSON file, discards the request body, and logs no IP address and no user agent. It sets no cookie and returns no identifier. It is not deployed on this site — GitHub Pages cannot execute server code — so nothing is currently sent anywhere. See F-11.

Reader capture

The subscription form is present on guide pages and the front page but is inert: with no endpoint configured it displays a notice saying so rather than accepting an address and discarding it. No email address submitted on this site is currently received or stored.

Before it is enabled, three things are needed, and they are prerequisites rather than follow-ups: a lawful basis for processing, a privacy notice describing it, and a working unsubscribe. The owner is in Zürich, so readers in Switzerland engage the Swiss FADP, readers in the EU engage GDPR, and readers in the UK engage the UK GDPR; marketing email to US readers engages CAN-SPAM. Amazon’s Operating Agreement also requires participation to comply with all applicable laws governing marketing email. See F-13 and S01.

Your controls

  • Clear this site’s storage in your browser settings to reset the five counters to zero.
  • Block localStorage for this origin and the counters will not persist; the site continues to work normally.
  • Disable JavaScript and the site remains fully readable. Every page is complete HTML with no client-side rendering, so nothing is hidden behind a script.

No contact address is published

None was supplied and inventing one would create an inbox nobody reads, which is worse than none. Corrections are handled in the open through the public repository.
