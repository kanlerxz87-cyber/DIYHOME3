# Measurement contract

The original prototype event schema is superseded. The editorial release has no newsletter or free-text tracking; RSS is the follow mechanism. The five enabled event types in the approved self-hosted profile are `page_view`, `guide_view`, `outbound_click`, `feed_click` and authenticated `reported_order` imports. See [configuration, payloads and privacy constraints](../README.md#self-hosted-analytics-not-deployed-on-pages). GitHub Pages does not execute the service and the client does not send telemetry from that host.
